# understand-me

Thinking-partner workflow for understanding, challenging, and refining ideas through explicit design decision trees.

This plugin packages the `understand-me` skill originally published on ClawHub by `guitenbay` and adapts it for the `claude-codeasier` Claude Code plugin marketplace.

## Included skills

- `/understand-me:understand-me`

## Local development

```bash
claude --plugin-dir ./plugins/understand-me
```

## Install from local marketplace

```text
/plugin marketplace add .
/plugin install understand-me@claude-codeasier
/reload-plugins
```
